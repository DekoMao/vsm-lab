MATERIAIS + INFORMAÇÃO

Mapa do estado atual

Arraste a barra horizontal para percorrer o mapa. Símbolos de estoque mostram quantidade e cobertura, não tempo de espera observado.

Dados de processo

CT = intervalo de repetição do ciclo. PT = tempo de processamento de uma unidade. Use dados da mesma família e período.

CT × disponibilidade não é usado para estimar capacidade. Setup e disponibilidade são dados de contexto. A ferramenta não calcula OEE, capacidade efetiva ou eficiência de valor agregado.

Use o mapa para orientar a coleta e a discussão.

Uma rota simples

De dois a oito processos em sequência, uma família e uma unidade por ciclo. Rotas alternativas, refugos, retrabalho, processos paralelos e lotes exigem adaptação. Não há conversão automática para essas situações.

Quatro medidas distintas

Takt = tempo líquido disponível ÷ demanda, no mesmo período. Cobertura = estoque ÷ demanda diária. PT é somado em segundos. Lead time observado é informado separadamente, em minutos decorridos.

Atual e futuro

“Atual” identifica o cenário registrado. A origem de cada processo permanece visível. “Futuro proposto” é uma hipótese editável, sem promessa de ganho. Copiar o atual não cria um sistema puxado.

Seus dados

O aplicativo processa os campos no navegador. Salvar grava uma cópia local, não um banco na nuvem. Exporte o JSON para guardar o projeto. Não insira dados confidenciais em computadores compartilhados.

Premissas, fórmulas e fontes técnicas

Não some cobertura de estoque em dias de demanda com minutos decorridos de lead time. A cobertura pode orientar investigação, mas não mede a espera real de uma peça. Nem todo processamento agrega valor. Setas contínuas indicam sequência de materiais; setas tracejadas são informação esquemática. Os símbolos não constituem uma biblioteca completa de VSM.

CT acima do takt sinaliza uma comparação a investigar sob a premissa de uma unidade por ciclo e um recurso por processo. CT abaixo do takt não comprova capacidade. Dados ausentes ou inválidos suspendem os cálculos, em vez de virar zero.
